# HyperMatch
**Right Creator. Right Brand. Right Hype.**

Responsive animated creator-discovery marketplace prototype focused on public Telugu creator profile references associated with Telangana and Andhra Pradesh.

## Included
- Nine connected sections: landing, discovery, campaign builder, matching, creator profiles, shortlist/comparison, saved campaigns, outreach drafts and methodology.
- Search and filters, explainable rule-based match scores, localStorage persistence, profile links, shortlist compare/copy, save/reopen/delete campaigns, outreach draft and copy.
- Premium navy/teal design, magnetic desktop cursor/buttons, scroll reveals, responsive layouts and reduced-motion support.
- Static HTML/CSS/JS. No build step, paid API or API key.

## Run locally
Open `index.html`, or run `python -m http.server 8000` from this folder.

## Publish free
1. Create a public repository at https://github.com/new.
2. Upload `index.html`, `README.md` and `vercel.json` to the repository root.
3. Go to https://vercel.com/new and import the repository.
4. Choose Framework Preset **Other**, leave build command blank, set output directory to `.` and deploy.
5. Test the public URL on desktop and mobile.

GitHub Pages alternative: Repository Settings → Pages → Deploy from a branch → `main` → `/(root)`.

## Data integrity
This is a prototype directory, not a fully verified influencer database. Some entries link to a public directory or search results instead of a confirmed canonical individual profile; those entries are explicitly marked for verification. Confirm handles, state association, niche and source before outreach. Follower counts, audience demographics, engagement rates and fees are not fabricated. Demo matching scores are illustrative relevance signals, not predictions of campaign success.

## Limitations
Browser-local storage only; no accounts or cross-device sync. Rule-based matching; no connected generative AI. No live analytics, automated messaging, payments or campaign delivery tracking.
